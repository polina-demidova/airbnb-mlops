# Airbnb Price Prediction

Учебный проект ML/DLOps, НИУ ВШЭ. Задача — регрессия цены аренды по характеристикам объявления Inside Airbnb.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```
Заполните AWS_ACCESS_KEY_ID и AWS_SECRET_ACCESS_KEY в `.env` выданными ключами. Остальные параметры уже заданы: Yandex Object Storage, bucket `mlops26-course-bucket`, key `prepared/listings.csv`. Не публикуйте `.env` и `secretkeys.py`.

```bash
jupyter lab
```

- `01_read_data.ipynb` — чтение S3 и проверка локального fallback. Локальная копия создаётся автоматически после успешного чтения.
- `01_training.ipynb` — самостоятельное чтение S3, подготовка признаков, разбиение 80/20, baseline и Random Forest, MAE, RMSE, R².
- `requirements.txt` — зависимости.

Запускайте ячейки сверху вниз. Ручное скачивание данных не требуется. Метрики вычисляются при запуске на реальных данных; заранее не заявляются.

## Обучение модели

Ноутбук: `01_training.ipynb`.

Задача: прогнозирование стоимости аренды жилья на основе характеристик объявлений Inside Airbnb.

Этапы работы:

- Загрузка данных из S3 с возможностью использования локальной копии.
- Исследовательский анализ данных (EDA).
- Удаление дубликатов и проверка целевой переменной.
- Логарифмическое преобразование цены.
- Разделение данных по listing_id с помощью GroupShuffleSplit.
- Обработка пропусков и кодирование категориальных признаков.
- Обучение Baseline и Random Forest.
- Оценка качества и анализ важности признаков.

### Результаты на тестовой выборке

| Model | MAE | RMSE | R² |
|---|---:|---:|---:|
| Baseline | 149.546 | 426.094 | -0.030 |
| Random Forest | 94.824 | 379.137 | 0.185 |

Random Forest снижает MAE на 36,6% и RMSE на 11,0% относительно Baseline.


## 3. Model Pipeline and Serialization

В ноутбуке `02_pipeline.ipynb` реализован единый sklearn Pipeline,
объединяющий предобработку данных и модель машинного обучения.

### Pipeline

- SimpleImputer — обработка пропущенных значений.
- OneHotEncoder — кодирование категориальных признаков.
- ColumnTransformer — объединение преобразований признаков.
- RandomForestRegressor — модель из 200 деревьев.
- TransformedTargetRegressor — логарифмирование целевой переменной
  и обратное преобразование предсказаний.

### Model evaluation

| Metric | Random Forest Pipeline |
|--------|------------------------|
| MAE    | 96.738                 |
| RMSE   | 382.317                |
| R²     | 0.171                  |

### Model serialization

Обученный Pipeline сохранён в формате pickle (`model.pkl`).
Размер модели составляет 198.96 МБ.

Проверено совпадение предсказаний до и после сериализации,
а также выполнение предсказания для нового объявления.

## Part 4. Docker and Batch Training

В рамках данного этапа реализовано автоматизированное обучение модели Random Forest в изолированном Docker-окружении.

### Реализованные компоненты

- `train.py` — скрипт загрузки данных из S3, предобработки, обучения модели, расчёта метрик и сериализации Pipeline.
- `Dockerfile.train` — конфигурация Docker-образа с необходимыми зависимостями.
- `docker-compose.yml` — конфигурация запуска batch training с подключением переменных окружения и сохранением артефактов модели.
- `.dockerignore` — исключение секретных ключей, локальных данных и моделей из контекста сборки.

### Запуск обучения

Для запуска необходимо настроить файл `.env` на основе `.env.example`.

Сборка Docker-образа:

```bash
docker compose build train
```

Запуск обучения:

```bash
docker compose run --rm train
```

Обученная модель сохраняется в `models/model.pkl` благодаря подключённому Docker volume.

### Результаты обучения

| Metric | Value |
|---|---:|
| MAE | 92.976 |
| RMSE | 350.326 |
| R² | 0.221 |

Размер обучающей выборки — 15 299 наблюдений, тестовой — 3 892 наблюдения. Пересечение объектов по `listing_id` отсутствует.

Размер сериализованной модели составляет 198.21 МБ.

Успешно проверены обучение модели внутри Docker-контейнера, сохранение Pipeline, его десериализация и сохранение артефакта после завершения работы контейнера.

Секретные ключи и файлы обученных моделей исключены из Git-репозитория.

## Часть 5. Разработка API для предсказания стоимости жилья

Реализован REST API на базе FastAPI для предсказания стоимости аренды жилья Airbnb в Лондоне. Сервис упакован в Docker-контейнер и интегрирован с контейнером обучения модели.

### Реализация

- `api.py` — FastAPI-приложение для получения предсказаний модели.
- `Dockerfile.api` — конфигурация Docker-образа API-сервиса.
- `docker-compose.yml` — конфигурация совместного запуска сервисов обучения и предсказания.
- Валидация входных данных с помощью Pydantic.
- Использование общего Docker volume для передачи обученной модели между контейнерами.
- Автоматический запуск API после успешного завершения обучения модели.

### Запуск приложения

```bash
docker compose up --build -d
```

Интерактивная документация Swagger UI доступна по адресу:

`http://127.0.0.1:8000/docs`

### Эндпоинты API

| Метод | Эндпоинт | Описание |
|---|---|---|
| GET | `/` | Основная информация о сервисе |
| GET | `/health` | Проверка работоспособности сервиса и доступности модели |
| POST | `/predict` | Предсказание стоимости аренды жилья |

### Результаты тестирования

- Проверка работоспособности сервиса — HTTP 200, модель успешно загружена.
- Запрос на предсказание с корректными входными данными — HTTP 200.
- Полученное предсказание стоимости для тестового объекта — 480.27.
- Запрос с некорректным типом входных данных — HTTP 422.
- Валидация входных данных работает корректно.

### Остановка приложения

```bash
docker compose down
```

В результате реализован контейнеризированный сервис предсказания стоимости аренды жилья с автоматическим обучением и загрузкой модели, валидацией входных данных и интерактивной документацией API.
