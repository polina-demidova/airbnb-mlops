# Airbnb Price Prediction

Учебный проект по курсу ML/DLOps, НИУ ВШЭ.

Цель проекта — разработка модели машинного обучения для прогнозирования стоимости аренды жилья Airbnb в Лондоне на основе характеристик объявлений Inside Airbnb, автоматизация процесса обучения и развёртывание модели в виде контейнеризированного REST API.

## Структура проекта

| Файл | Описание |
|---|---|
| `01_read_data.ipynb` | Загрузка данных из S3 и проверка локальной копии |
| `01_training.ipynb` | Исследовательский анализ данных, обучение и оценка моделей |
| `02_pipeline.ipynb` | Построение sklearn Pipeline и сериализация модели |
| `train.py` | Скрипт автоматизированного обучения модели |
| `api.py` | REST API для получения предсказаний |
| `Dockerfile.train` | Конфигурация Docker-образа для обучения |
| `Dockerfile.api` | Конфигурация Docker-образа для API |
| `compose.yaml` | Конфигурация совместного запуска контейнеров |
| `requirements.txt` | Зависимости проекта |
| `.env.example` | Шаблон переменных окружения |
| `.gitignore` | Исключения для Git |
| `.dockerignore` | Исключения для контекста сборки Docker |
| `README.md` | Документация проекта |

## 1. Подготовка окружения и загрузка данных

### Клонирование репозитория

```bash
git clone https://github.com/polina-demidova/airbnb-mlops.git
cd airbnb-mlops
```

### Настройка доступа к данным

Создайте файл `.env` на основе предоставленного шаблона:

```bash
cp .env.example .env
```

Заполните `AWS_ACCESS_KEY_ID` и `AWS_SECRET_ACCESS_KEY` выданными в рамках курса ключами доступа.

Остальные параметры уже заданы в `.env.example`:

- S3 Endpoint: `https://storage.yandexcloud.net`
- Регион: `ru-central1`
- Bucket: `mlops26-course-bucket`
- Key: `prepared/listings.csv`

Данные хранятся в Yandex Object Storage и загружаются автоматически при запуске ноутбуков или скрипта обучения. Ручное скачивание датасета не требуется.

Для доступа к данным необходимы действующие ключи учебного S3.

Файлы `.env` и `secretkeys.py` исключены из Git-репозитория.

### Настройка локального Python-окружения

Для работы с ноутбуками необходимо создать виртуальное окружение и установить зависимости:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Запуск JupyterLab:

```bash
jupyter lab
```

Ноутбуки необходимо запускать последовательно, выполняя ячейки сверху вниз:

1. `01_read_data.ipynb` — загрузка данных из S3 и проверка локального fallback. Локальная копия создаётся автоматически после успешного чтения.
2. `01_training.ipynb` — исследовательский анализ данных, подготовка признаков, обучение и оценка моделей.
3. `02_pipeline.ipynb` — построение единого Pipeline, сериализация и проверка модели.

Для запуска проекта через Docker создание локального Python-окружения не требуется.

## 2. Обучение модели

Ноутбук: `01_training.ipynb`.

Задача — прогнозирование стоимости аренды жилья на основе характеристик объявлений Inside Airbnb.

### Этапы работы

- Загрузка данных из S3 с возможностью использования локальной копии.
- Исследовательский анализ данных (EDA).
- Удаление дубликатов и проверка целевой переменной.
- Логарифмическое преобразование цены.
- Разделение данных на обучающую и тестовую выборки в пропорции 80/20 с группировкой по `listing_id` с помощью GroupShuffleSplit.
- Обработка пропущенных значений и кодирование категориальных признаков.
- Обучение Baseline и Random Forest.
- Оценка качества моделей и анализ важности признаков.

### Результаты на тестовой выборке

| Модель | MAE | RMSE | R² |
|---|---:|---:|---:|
| Baseline | 149.546 | 426.094 | -0.030 |
| Random Forest | 94.824 | 379.137 | 0.185 |

Random Forest снижает MAE на 36,6% и RMSE на 11,0% относительно Baseline.

В таблице представлены результаты, полученные при выполнении ноутбука на реальных данных.

## 3. Построение Pipeline и сериализация модели

В ноутбуке `02_pipeline.ipynb` реализован единый sklearn Pipeline, объединяющий предобработку данных и модель машинного обучения.

### Компоненты Pipeline

- SimpleImputer — обработка пропущенных значений.
- OneHotEncoder — кодирование категориальных признаков.
- ColumnTransformer — объединение преобразований числовых и категориальных признаков.
- RandomForestRegressor — модель случайного леса из 200 деревьев.
- TransformedTargetRegressor — логарифмирование целевой переменной и обратное преобразование предсказаний.

### Результаты оценки модели

| Метрика | Random Forest Pipeline |
|---|---:|
| MAE | 96.738 |
| RMSE | 382.317 |
| R² | 0.171 |

### Сериализация модели

Обученный Pipeline сохранён в формате pickle (`model.pkl`).

Размер сериализованной модели составляет 198.96 МБ.

Проверено:

- Совпадение предсказаний до и после сериализации.
- Успешная десериализация модели.
- Выполнение предсказания для нового объявления.

Модель также была загружена в S3:

`s3://mlops26-course-bucket/models/model.pkl`

Файл модели исключён из Git с помощью `.gitignore`. Для запуска контейнеризированного приложения предварительное скачивание модели не требуется: она создаётся автоматически при обучении.

## 4. Контейнеризация и автоматизированное обучение

Реализовано автоматизированное обучение модели Random Forest в изолированном Docker-окружении.

### Реализованные компоненты

- `train.py` — скрипт загрузки данных из S3, предобработки, обучения модели, расчёта метрик и сериализации Pipeline.
- `Dockerfile.train` — конфигурация Docker-образа с необходимыми зависимостями.
- `compose.yaml` — конфигурация запуска batch training с подключением переменных окружения и сохранением артефактов модели.
- `.dockerignore` — исключение секретных ключей, локальных данных и моделей из контекста сборки.

### Запуск обучения

Для запуска необходимы установленные Docker и Docker Compose, а также настроенный файл `.env`.

Создание директории для хранения модели:

```bash
mkdir -p models
```

Сборка Docker-образа:

```bash
docker compose build train
```

Запуск обучения:

```bash
docker compose run --rm train
```

В процессе выполнения скрипта автоматически происходят:

1. Загрузка датасета из S3.
2. Очистка и подготовка данных.
3. Разделение данных на обучающую и тестовую выборки.
4. Обучение Random Forest Pipeline.
5. Расчёт метрик качества.
6. Сериализация модели.
7. Проверка корректности десериализации.

Обученная модель сохраняется в `models/model.pkl` благодаря подключённой директории хостовой системы (bind mount). Артефакт сохраняется после завершения работы контейнера.

### Результаты обучения

| Метрика | Значение |
|---|---:|
| MAE | 92.976 |
| RMSE | 350.326 |
| R² | 0.221 |

Размер обучающей выборки — 15 299 наблюдений, тестовой — 3 892 наблюдения.

Пересечение объектов по `listing_id` отсутствует.

Размер сериализованной модели составляет 198.21 МБ.

Успешно проверены обучение модели внутри Docker-контейнера, сохранение Pipeline, его десериализация и доступность артефакта после завершения работы контейнера.

Секретные ключи и файлы обученных моделей исключены из Git-репозитория.

## 5. Разработка API для предсказания стоимости жилья

Реализован REST API на базе FastAPI для предсказания стоимости аренды жилья Airbnb в Лондоне. Сервис упакован в Docker-контейнер и интегрирован с контейнером обучения модели.

### Реализованные компоненты

- `api.py` — FastAPI-приложение для получения предсказаний модели.
- `Dockerfile.api` — конфигурация Docker-образа API-сервиса.
- `compose.yaml` — конфигурация совместного запуска сервисов обучения и предсказания.
- Валидация входных данных с помощью Pydantic.
- Использование общей директории для передачи обученной модели между контейнерами.
- Подключение директории с моделью к API-контейнеру в режиме read-only.
- Автоматический запуск API после успешного завершения обучения модели.
- Интерактивная документация Swagger UI.

### Запуск приложения

Убедитесь, что Docker запущен, а файл `.env` содержит действующие ключи доступа к S3.

Выполните из корневой директории проекта:

```bash
mkdir -p models
docker compose up --build -d
```

Docker Compose автоматически:

1. Собирает Docker-образы для обучения и API.
2. Запускает контейнер обучения.
3. Загружает данные из S3 и обучает модель.
4. Сохраняет обученную модель в `models/model.pkl`.
5. После успешного завершения обучения запускает API-сервис.
6. Загружает сохранённую модель для выполнения предсказаний.

Для просмотра процесса обучения и запуска API:

```bash
docker compose logs -f
```

Для проверки состояния контейнеров:

```bash
docker compose ps -a
```

После завершения обучения контейнер `train` должен завершиться с кодом 0, а контейнер `api` продолжить работу.

Интерактивная документация Swagger UI доступна по адресу:

http://127.0.0.1:8000/docs

### Эндпоинты API

| Метод | Эндпоинт | Описание |
|---|---|---|
| GET | `/` | Основная информация о сервисе |
| GET | `/health` | Проверка работоспособности сервиса и доступности модели |
| POST | `/predict` | Предсказание стоимости аренды жилья |

### Проверка работоспособности сервиса

Запрос:

```bash
curl http://127.0.0.1:8000/health
```

Ожидаемый ответ:

```json
{
  "status": "ok",
  "model_loaded": true
}
```

Код ответа: HTTP 200.

### Пример запроса на предсказание

```bash
curl -X POST "http://127.0.0.1:8000/predict" \
  -H "Content-Type: application/json" \
  -d '{
    "latitude": 51.5074,
    "longitude": -0.1278,
    "accommodates": 4,
    "bathrooms": 1.0,
    "bedrooms": 2,
    "beds": 2,
    "minimum_nights": 2,
    "neighbourhood_cleansed": "Westminster",
    "property_type": "Entire rental unit",
    "room_type": "Entire home/apt"
  }'
```

Полученный при тестировании ответ:

```json
{
  "predicted_price": 480.27
}
```

Код ответа: HTTP 200.

Значение предсказания может отличаться при изменении исходных данных или повторном обучении модели.

Запрос также можно выполнить через Swagger UI, выбрав эндпоинт `POST /predict`, нажав `Try it out` и передав характеристики объявления в формате JSON.

### Проверка валидации входных данных

При передаче некорректного типа данных, например строкового значения `"abc"` вместо целого числа в поле `accommodates`, API возвращает HTTP 422 с описанием ошибки валидации.

Валидация выполняется с помощью Pydantic до передачи данных в модель.
